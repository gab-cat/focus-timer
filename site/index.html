How it decides

It only moves when you don't.

Nothing happens until you've been idle for a couple of minutes. Calls, a locked screen and, if you like, battery power make it stand down.

Sleep, blocked. Even with the lid shut.

With Block system sleep on, a session holds off sleep with pmset until it ends. Then everything goes back to normal.

Session starts $pmset -a disablesleep 1 Sleep blocked
Session ends $pmset -a disablesleep 0 Sleep restored

No password, if you'd rather

Skip the password installs a sudoers rule that allows only those two pmset commands. It's checked with visudo before it goes live, and Remove takes it out again.

Restored after a crash

If the app quits mid-session, the next launch puts sleep back the way it was.

Or keep it light

Switch it off and a session simply keeps the display awake with caffeinate.

Questions, answered.

Something else on your mind? Open an issue on GitHub.

Will it get in my way while I'm working?
No. Before every move it checks how long you've been idle. If you touched the keyboard or mouse inside the threshold (two minutes by default), it waits again instead of moving.
Why does it ask for my password?
Blocking system sleep uses pmset, which needs admin rights, so macOS asks when a session starts and ends. Turn on Skip the password in Settings to install a rule that allows just those two commands.
Does it send my data anywhere?
No. Your counts, heatmap and action mix are stored on your Mac. The only thing it fetches is the update check from GitHub Releases.
Which Macs does it run on?
The release build is for Apple Silicon Macs. The full source is on GitHub if you'd like to build it yourself with Bun.
Why does macOS warn me when I open it?
The app is signed ad hoc rather than notarized by Apple, which is common for small open-source tools. You only need to allow it once.
Is it OK to use at work?
Use it where you're allowed to. It's made for presenting, reading, watching long jobs and holding a focus block together, and it should always be used within your workplace, school and client policies.
Does it cost anything?
No. It's free, and every line of it is on GitHub.
